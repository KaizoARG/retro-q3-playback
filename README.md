# Retro Flow · MVP

MVP frontend-only de una retrospectiva interactiva.

## Ejecutar
Abrí `index.html` directamente en el navegador.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub.
2. Subí `index.html`, `style.css` y `app.js`.
3. En **Settings → Pages**, seleccioná la rama principal y `/root`.
4. Guardá. GitHub Pages generará la URL pública.
